# Ghi Janicr 个人主页

推广远程线上工作与 AI 技能项目的静态个人主页，纯 HTML / CSS / JS，无需构建。

## 部署（Cloudflare Pages）

- 连接本仓库，Framework preset 选 **None**
- Build command 留空，Build output directory 填 `/`
- 推送到 `main` 分支即自动部署

## 修改内容

- 文字与平台列表：`index.html`
- 样式与配色：`style.css`（顶部 `:root` 变量）
- 联系邮箱：搜索 `hello@example.com` 替换
